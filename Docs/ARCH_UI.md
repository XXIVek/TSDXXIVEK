## Состояния (bd, input, output)

### bd (состояние БД)

| Значение | Описание |
|:---:|------|
| 0 | База пуста |
| 1 | Ошибка работы с БД |
| 2 | База загружена, есть записи для выгрузки |
| 3 | База загружена, данных для выгрузки нет |
| -1 | Идёт загрузка |

### input (состояние входящих данных)

| Значение | Описание |
|:---:|------|
| 0 | Нет данных |
| 1 | Ошибка |
| 3 | Есть данные |
| 6 | Данные получены |
| -1 | Ошибка |

### output (состояние исходящих данных)

| Значение | Описание |
|:---:|------|
| 0 | Нет данных для выгрузки |
| 1 | Ошибка выгрузки |
| 2 | Не определено |
| 3 | Данные отправлены |
